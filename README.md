# Munger–Buffett Operating System

A decision system distilled from the primary sources of Charlie Munger and
Warren Buffett — built source-first, then synthesized into a cited framework
anyone can use. Built August 2026. Source cutoff: August 3, 2026.

By Athan Tsokolas. Licensed under [CC BY 4.0](LICENSE).

## What this is

Munger and Buffett did not win because they possessed a secret valuation
formula. They built an unusually coherent system for reducing avoidable error
and allowing a few good decisions to compound for a very long time. This
repository is that system, written down:

- **12 principles** — from avoiding ruin first to protecting uninterrupted
  compounding ([executive-brief.md](executive-brief.md)).
- **A 10-step master decision sequence** with a one-page decision-record
  template, plus variants for investing, product calls, hiring, spending, and
  AI assistants ([operating-framework.md](operating-framework.md),
  [decision-record.md](decision-record.md)).
- **A 9-layer error-control architecture** — the latticework, two-track
  analysis, inversion, psychology checklist, and deserved trust, in Munger's
  own working order ([notes/munger-core-framework.md](notes/munger-core-framework.md)).
- **A cited chronological reference** — how the philosophy evolved, where the
  two men disagreed, and where it breaks ([cited-reference.md](cited-reference.md)).
- **A methodology audit** — source grades, coverage, provenance limits, and
  the anti-hagiography controls that kept the study honest
  ([methodology-and-corpus.md](methodology-and-corpus.md)).

## What this is not

- **Not a quote book.** The synthesis is overwhelmingly original paraphrase and
  analysis. Do not optimize for famous quotations; optimize for repeated
  principles, changes across decades, the conditions under which advice
  applies, and disconfirming evidence.
- **Not the corpus.** The 145 primary sources behind this study are
  copyrighted material and are not distributed here. See
  [corpus-sources.md](corpus-sources.md) for how to rebuild the corpus
  yourself from public archives.
- **Not investment advice.** This is a method for making decisions, not a
  recommendation about any security.
- **Not a live corpus.** Nothing after August 3, 2026 is in it, and 7 of the
  145 items were image-only and never extracted as text.

## The quotation rule

The corpus grades every source family A–D by provenance (see
[methodology-and-corpus.md](methodology-and-corpus.md)):

- **Grade A or clean Grade B:** quotable, after checking the underlying text.
- **Grade C** (meeting notes, third-party transcripts): paraphrase; exact
  wording needs independent confirmation.
- **Grade D:** discovery only. No load-bearing quotation.

File availability does not imply quotation fitness.

## Rebuild the corpus (the 145 items)

[corpus-sources.md](corpus-sources.md) lists every item's public source URL,
grouped by collection, with the fetch method and the limits for each source
family (including the 1970–1976 Berkshire gap and the image-only items that
need OCR). The method: download from the source, extract text, read
chronologically in bounded tranches, record principles, changes, boundary
conditions, and disconfirming evidence.
