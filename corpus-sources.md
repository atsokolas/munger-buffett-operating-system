# Corpus sources — how to get the 145 items

The corpus behind this study is **not in this repository**. Its 145 items are
copyrighted primary sources — Berkshire's letters, Munger's speeches and essays,
meeting transcripts, and archival scans. Distributing them would be copyright
infringement. Instead, this file lists every item's public source so anyone can
rebuild the corpus themselves.

Built August 2–4, 2026. Source cutoff August 3, 2026. Items: 145 total — 138 downloaded_extracted, 7 downloaded_image_only.

## Method

1. Download each item from its source URL below.
2. Extract text. HTML pages: save the article text. PDFs: extract with a tool
   like `pdftotext`; the 7 image-only items need OCR first (e.g. `ocrmypdf` or
   Tesseract) — they are marked `image-only` below.
3. Keep the manifest fields per item: person, collection, year, source URL,
   format, and status. Do not renumber or silently substitute items.
4. Read chronologically in bounded tranches rather than searching only for known
   phrases, and record principles, changes across decades, boundary conditions,
   and disconfirming evidence as you go.

## Notes and limits

- Berkshire's official letter archive begins its separately posted annual letters
  in 1977. The 1970–1976 transition period was closed from a compiled
  third-party text-bearing PDF plus image-heavy annual-report backups: reliable
  for thematic chronology, not for fragile word-for-word quotation.
- Wesco and Daily Journal annual-meeting material is largely third-party
  transcript or attendee notes, not official verbatim text. Use it for themes
  and triangulation; paraphrase load-bearing material unless independently
  confirmed. See `methodology-and-corpus.md` for the grade for each source family.
- Mirrors move and links rot. If a source URL is dead, the collection name and
  year above are enough to locate an equivalent faithful copy; prefer official
  or university-hosted copies over quote sites, and never treat a quote site as
  final evidence.
